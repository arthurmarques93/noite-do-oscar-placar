Trocar a fase

Por segurança, esta página só lê dados. Para mudar a fase, copie o comando e rode no SQL Editor do Supabase. Os apps abertos mudam de tela sozinhos em poucos segundos.

Reabrir indicaçõesupdate app_state set phase = 'nomination';
Abrir votação finalupdate app_state set phase = 'final';
Revelar vencedoresupdate app_state set phase = 'closed';
